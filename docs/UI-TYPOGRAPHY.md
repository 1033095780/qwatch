# qwatch 字体与排版规范

> 目标：统一层级，避免「标题很大、正文很小」的割裂感。所有页面、卡片、列表共用同一套字号。

## 字号阶梯

| Token | 字号 | 用途 |
|---|---:|---|
| `--fs-10` | 10px | 图表时间轴、极小状态角标；正文不再使用 |
| `--fs-11` | 11px | 列表辅助信息、时间、卡片脚注 |
| `--fs-12` | 12px | 次级正文、表单标签、表头 |
| `--fs-13` | 13px | 正文、列表主文案、按钮 |
| `--fs-14` | 14px | 卡片标题、Tab 当前项 |
| `--fs-16` | 16px | 顶栏页面标题、区块主标题 |
| `--fs-18` | 18px | 强调数字、详情页小标题 |
| `--fs-20` | 20px | 中号金额、账户名 |
| `--fs-24` | 24px | KPI 主数字 |
| `--fs-28` | 28px | 大屏/重点 KPI |

## 使用规则

1. **正文最低 11px**，仅图表坐标、极少数角标允许 10px。
2. 同一层级内不混用 8/9/10/11 多个字号；列表辅助信息统一 11px。
3. 数值统一使用等宽字体，标题和正文使用无衬线字体。
4. 页面标题只出现一次：顶栏面包屑就是页面标题；内容区不再重复大标题。
5. 卡片标题 14px，卡片内辅助信息 11px，主金额 20–28px。
6. 行高：正文 1.5，紧凑列表 1.35，KPI 数字 1.1。
7. 不为塞内容把字号降到 10px 以下；优先减少信息或让面板内部滚动。

## 当前落点

- 顶栏页面标题：16px / 600
- KPI 标签：12px；主数字：25px；脚注：10px
- 动态列表：正文 11px；时间 10px；类型标签 10px
- 告警列表：策略名 11px；摘要 10px；状态 10px
- 策略卡片：名称 14px；辅助信息 11px；权益 23px；今日 11px
- 详情页 / 账户页标题保留 24px

## 禁止

- 用 8px、9px 作为常规正文
- 同一个列表里字号忽大忽小
- 为了一屏硬压字号；优先滚动、折叠或减少次要信息
